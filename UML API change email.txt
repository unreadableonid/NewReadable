@startuml

actor "User" as User
participant "UI" as UI
participant "API Gateway" as Gateway
participant "Сервис Пользователей" as AccountService
database "DB Account" as DataBase
queue "Kafka" as Broker
participant "Сервис Уведомлений" as NotificationService

User -> UI: Изменить email
activate User
activate UI

UI -> Gateway: PATCH /api/accounts/{username}
activate Gateway

Gateway -> AccountService: PATCH /api/accounts/{username}
deactivate Gateway
activate AccountService

AccountService -> AccountService: Проверка авторизации

alt Неверный пароль

AccountService --> UI: Пароли не совпадают

UI --> User: Запрос пароля

User -> UI: Ввести пароль

UI -> Gateway: PATCH /api/accounts/{username}
activate Gateway

Gateway -> AccountService: PATCH /api/accounts/{username}
deactivate Gateway
end alt

AccountService -> DataBase: Проверка email
activate DataBase

DataBase --> AccountService: Вернуть результат
deactivate DataBase

alt Email занят

AccountService --> UI: Некорректный Email

UI --> User: Email занят

User -> UI: Ввести другой email

UI -> Gateway: PATCH /api/accounts/{username}
activate Gateway

Gateway -> AccountService: PATCH /api/accounts/{username}
deactivate Gateway

end alt

AccountService ->> Broker: Смена email
activate Broker

AccountService --> UI: Запрос принят
deactivate UI
deactivate AccountService

NotificationService -->> Broker: Подписка на топик
activate NotificationService

Broker ->> NotificationService: Смена email
deactivate Broker

NotificationService --> User: Отправить уведомление
deactivate NotificationService

UI --> User: Проверить email
activate UI

User -> UI: Подтвердить изменение

UI -> Gateway: POST /api/accounts/email
activate Gateway

Gateway -> AccountService: POST /api/accounts/email
deactivate Gateway
activate AccountService

AccountService -> DataBase: Изменить email
activate DataBase

DataBase --> AccountService: OK
deactivate DataBase

AccountService --> UI: OK
deactivate AccountService

UI --> User: Email изменен
deactivate User
deactivate UI

@enduml
